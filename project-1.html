Electronic Chessboard Project

← All projects

Summary

Over a ten-week university trimester, I designed and built a proof-of-concept electronic chessboard using induction coils and passive resonant identification circuits embedded within chess pieces to detect both their position and identity.

The system integrated a custom-designed PCB, bespoke firmware, and a CSS-based software interface communicating over serial with Lichess to retrieve opening data in response to user moves, with the long-term goal of creating an interactive chess opening trainer.

Given the project's ambitious scope, spanning 3D CAD design in Fusion, PCB development, laser cutting, electrical engineering, and hardware testing, the prototype demonstrated the core functionality of each subsystem but did not reach full implementation across all 64 squares within the available timeframe.

Ltspice Modelling and Simulation

I used LTspice to model and optimise the induction coil circuits, determining practical component values and validating simulations against experimental magnetic coupling results. This informed the selection of wire gauge and coil turns within physical constraints, maximising magnetic coupling before PCB design and fabrication.


Each piece contains a passive resonant circuit which when excited at a specific pre-defined frequency will cause a significant voltage drop across the coil which can be detected and measured by the microcontroller.



PCB Design

The KiCad schematic is a replication of the setup I had made using a breadboard with extra elements such as USB-C connector, static discharge protection and peripherals taken from each ICs respective data sheet.




Fusion 360 Design

This the final iteration of the physical chessboard, each square is 55mm by 55mmm (which is standard tournament size) with compartments for the LEDs and induction coils. The board acts as an opening database via a custom software which can communicate to Lichess to retrieve popular moves based on the position, with the custom firmware controlling all voltage thresholds for the board.

Outcome

Gained valuable skills in PCB design and implementation, modelling/simulating real world systems, 3D design, firmware and software design.
